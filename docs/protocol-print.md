# Протокол печати KX-MB2020 (Panasonic GDI)

Восстановлен по захвату задания штатного драйвера «Panasonic KX-MB2020 GDI» 1.048 (Windows x64) на порт RAW TCP 9100. Свой поток, собранный по этому описанию, совпадает с драйверным байт в байт (страница A4, 600 dpi).

## Транспорт

Одно TCP-соединение ПК → МФУ:9100, только данные (ответов нет). Параллельно штатный порт Windows опрашивает Printer/Host MIB по SNMP (UDP 161), а МФУ шлёт SNMP TRAP (Panasonic, 1.3.6.1.4.1.258.406…) на ПК UDP 2081 со статусом задания.

## Структура задания

```
ESC%-12345X
@PJL COMMENT Panasonic KX-MB2020 GDI
@PJL COMMENT TREATASCHARACTER
@PJL COMMENT version AMD64 5.01.032.001
@PJL COMMENT DriverVersion="1.048(1.048.002.e)"
@PJL COMMENT DriverOrgVer="0.048.000.e"
@PJL COMMENT OSVersion="Windows 10.0;Build NNNNN;AMD64"
@PJL COMMENT Monochrome MFP
@PJL COMMENT Soc Type=Sirius
@PJL JOB TIME="yyyy/MM/dd HH:mm:ss"
@PJL JOB NAME="<имя документа>"
@PJL JOB OWNER="<пользователь>"
@PJL JOB HOST="<имя ПК>"
@PJL JOB PCIP="<IP ПК>"
@PJL SET RET=ON
@PJL SET ECONOMODE=OFF
@PJL SET COPIES=1
@PJL SET DUPLEX=OFF
@PJL ENTER LANGUAGE=GDI
```

(строки PJL разделены `\n`; что из COMMENT/JOB обязательно для МФУ — не проверено)

### Начало страницы

| Команда | Значение (наблюдалось) |
|---|---|
| `ESC&&0S` | ? |
| `ESC&r600W`, `ESC&r600L` | разрешение 600×600 dpi |
| `ESC&&0Y` | ? |
| `ESC&l26A` | размер бумаги A4 (код как в PCL) |
| `ESC&l2H` | источник бумаги (лоток #1?) |
| `ESC&&11W` | ? |
| `ESC*r6814T` | высота растра, строк |
| `ESC*r4760S` | ширина растра, пикселей (кратна 8) |
| `ESC&a100L`, `ESC&l100E` | поля/отступы? |
| `ESC&&0T` | ? |

4760×6814 при 600 dpi = 201,5 × 288,4 мм — это печатаемая область A4 (жёсткие поля ~4,23 мм).

### Полосы растра

Страница режется на полосы по 512 строк (последняя — остаток), каждая:

```
ESC*b0W
u32 LE  длина BIE (BIH + SDE + завершающий FF 02)
u32 LE  флаги: 0x00010000 — первая полоса, 0x00000001 — последняя, иначе 0
u8      0x0B
u8      0
u16 LE  число строк в полосе (512 / остаток)
u32     0
...     JBIG-1 BIE (ITU-T T.82)
```

BIE: BIH 20 байт — `DL=0 D=0 P=1 0`, `XD`=ширина, `YD`=строк полосы, `L0=YD` (одна полоса), `MX=0 MY=0`, `order=0`, `options=0x48` (LRLTWO — двухстрочный шаблон, TPBON — типовое предсказание строк). Затем SDE и маркер `FF 02` (SDNORM). Особенность кодера Panasonic: перед `FF 02` всегда дописан лишний байт `0x00` (jbig-kit его не выводит).

Пиксель 1 = чёрный. Пустые полосы с одинаковыми строками сжимаются до ~13 байт SDE.

### Конец задания

```
ESC&&1R
ESC%-12345X@PJL EOJ NAME="<имя документа>"
ESC%-12345X
```

## Открытые вопросы

- Значения `ESC&&…` команд, коды других форматов бумаги, лотков, 300 dpi, экономия тонера, несколько страниц/копий.
- Что МФУ проверяет в PJL (можно ли сократить заголовок).
